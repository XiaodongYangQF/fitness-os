# Fitness OS v0.2 Mobile MVP

A mobile-first Streamlit app for personal nutrition, training and weight management.

## Features

- English mobile-first UI
- Today dashboard
- Smart meal builder using a custom food database
- Training planner based on soreness, fatigue and previous workout load
- Workout log
- Body metrics and stool status log
- Progress charts
- Food database CSV upload
- Old workout spreadsheet preview/import page

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Cloud

Use:

```text
Branch: main
Main file path: app.py
```

If you upload this whole folder into a subdirectory, use the corresponding path, for example:

```text
fitness_mvp_app/app.py
```
